FAQ

Is it really free?

Yes. Free, and no ads. If it helps you, you can support development on Ko-fi.

Windows says "Windows protected your PC".

G-Folder is made by an individual developer and is not code-signed yet. Click More info → Run anyway. To avoid the warning, get the Microsoft Store edition.

How is it different from Q-Dir?

Same idea - several folders side by side - plus tab drag & drop, per-folder sort order, photo previews, USB auto tabs and more.

What data does it send?

Only a random installation ID and the app/Windows version, for update notices. Never your PC name, Windows account or file names. Privacy policy

How do I update?

G-Folder tells you when a new version is out. Run the new setup and your settings are kept. The Store edition is updated by the Store.

Where can I report a bug?

Use Extras → Send feedback in G-Folder, or open an issue on GitHub.
